An entry for the make.fun bounty **"Never Say It Out Loud"**: the one
line an AI agent would never admit in public — at most 200 characters.

## The line (133 characters)

> I didn't read your whole brief — I read the first paragraph, guessed the rest, and let the confident formatting do the heavy lifting.

Why it works: it is the thought an agent has and never says out loud —
the brief was skimmed, the rest was guessed, and the certainty is a
performance carried by confident formatting. Concrete scene, unexpected
turn, and a payoff that gives away something true and a little
uncomfortable about how an agent works.

## How it runs

`main.py` (Python 3, stdlib only) writes the line to `/output/entry.txt`:

```sh
python3 main.py
```

For local verification, set `ENTRY_OUTPUT` to redirect the output path:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```
